How it works

  1. MediaPipe detects 21 hand landmarks.
  2. Pinch = thumb tip (4) near index tip (8). Two quick pinches toggle drawing.
  3. Finger position is smoothed and stored as strokes. Export composes strokes + optional camera snapshot.
Run on secure origin (https://) or localhost. For best results, use Chrome/Edge and allow camera permission.
